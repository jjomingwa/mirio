# 아키텍처와 완료 계약

## 경계

```text
React UI <-> typed EventBus <-> Phaser scenes
                                  |
                         domain data + save
                                  |
                    AudioDirector / CourseBuilder
```

Phaser 장면은 프레임 단위 물리 상태를 소유한다. React는 생명, 왕관 조각, 시간, 음량처럼 화면 표시와 설정에 필요한 저빈도 상태만 받는다. 월드·코스 데이터는 Zod로 앱 시작 시 한 번 검증한다.

## 저장 계약

로컬 저장은 버전, 현재 노드, 해금 월드, 클리어 노드, 비밀 출구, 코스별 왕관 조각, 목숨, 코인, 설정을 포함한다. 알 수 없는 키와 잘못된 값은 Zod 검증 후 기본값으로 복구한다. 스테이지 클리어와 설정 변경 시 자동 저장한다.

## 월드 그래프 계약

- 노드 ID는 전체 게임에서 유일하다.
- 모든 연결 대상은 존재한다.
- 시작 노드에서 일반 진행만으로 월드 8 최종전에 도달 가능하다.
- 월드 2 비밀 출구는 월드 4를, 일반 출구는 월드 3을 연다.
- 월드 5 비밀 출구는 월드 7을, 일반 출구는 월드 6을 연다.
- 각 월드에는 왕관 수호자 보스 노드가 있다.
- 최종 베스페라 노드는 정확히 하나다.
- 전체 플레이 가능 노드는 정확히 54개다.

## 완료 증거

구현 완료를 주장하려면 다음을 모두 확인한다.

1. 데이터 검사: 8월드, 54노드, 유효한 연결, 두 개의 대분기, 최종전 도달성.
2. 빌드 검사: 엄격한 TypeScript와 Vite 프로덕션 빌드 성공.
3. 단위 검사: 저장 마이그레이션, 그래프 해금, 코스 생성 결정성.
4. 브라우저 검사: 오프닝→월드맵→코스→보스→다음 월드→엔딩 흐름.
5. 입력 검사: 키보드, 게임패드, 터치, 일시정지와 설정.
6. 시각 검사: 16:9, 좁은 화면, 고해상도, 픽셀 스케일, UI 겹침.
7. 음향 검사: 사용자 제스처 이전 무음, 음량 버스, 중복 SFX 제한, 음악 전환.

최종 검증 방식은 사용자 요청대로 구현 완료 후 다시 합의한다.
