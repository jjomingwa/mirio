# Crowntrail Kingdom v2 Identity Bible

## Premise & Core Motif

"따뜻한 금빛 동화가 먹빛 균열에 침식되고, 여우가 움직일 때만 왕관의 빛이 길을 만든다."

## Visual Rules

- **Internal Resolution**: 640×360 (Virtual 16:9 16-bit fairy-tale pixel grid, nearest-neighbor scaling).
- **Tile Grid**: 32×32px.
- **Character Proportions**: Player ~~48px tall, Common Enemies 32~~44px, Bosses 112~144px.
- **Normal Palette**: Cream (#FFF8E7), Amber (#FFC857), Warm Green (#4B7F52), Teal (#2A9D8F).
- **Corruption Palette**: Ink Violet (#2B1B36), Desaturated Blue (#3A405A), Cold Magenta (#8B4A6A).
- **Gameplay Outlines**: Darkest value foreground outline, Target gold rim (#FFD700), Hazard red double-chevron (#E63946).
- **Camera Rules**: Max 4px screen shake on heavy impact; no dizzying fast zooms.

## Four Key Screens

1. **Title Screen**: Warm golden crown emblem against an encroaching ink-violet sky.
2. **Fairy-tale World Map**: Storybook map with illuminated nodes and branching paths.
3. **Level Play**: Goldenwind Forest with 3 parallax layers, platforming hazards, and gold target rings.
4. **Boss / Ending**: Broken Throne hall with telegraphed boss attacks and clear win condition.

## Audio & Accessibility Guidelines

- **Audio Motifs**: Warm acoustic melody during exploration, tense brass/strings in fortress/boss encounters.
- **Accessibility Variants**:
  - Reduced Motion: Disables camera shake and fast zooms; retains clear static target indicators.
  - Reduced Flash: Replaces full-screen white flashes with soft gold outline pulses.
  - Muted Audio: Provides explicit visual toasts and target lock cues for all key game events.
