# Crowntrail Kingdom

분기형 월드맵과 수집·탐험을 중심으로 만든 독립적인 횡스크롤 어드벤처입니다. 공개 라이선스 픽셀아트와 고유 세계관을 사용합니다.

## 핵심 경험

- 짧은 오프닝 애니메이션과 타이틀 연출
- 칸을 한 칸씩 이동하는 분기형 월드맵
- 8개 월드, 54개 플레이 가능 코스
- 일반 출구와 비밀 출구가 만드는 월드 3/4, 월드 6/7 분기
- 각 월드의 왕관 수호자 전투와 월드 8의 왕관 포식자 베스페라 최종전
- 코요테 타임, 점프 버퍼, 가변 점프, 달리기 관성, 체크포인트
- 3개의 왕관 조각, 비밀 출구, 스테이지 기록과 자동 저장
- Web Audio 기반 음악 크로스페이드, SFX 동시 재생 제한, 독립 음량 버스
- 키보드·게임패드·터치 지원 및 흔들림/플래시/음량 접근성 옵션

## 실행

```powershell
npm install
npm run dev
```

검증 명령은 구현 완료 후 사용자와 검증 방법을 합의한 뒤 실행합니다.

## 구조

- `src/game/data`: 8개 월드와 54개 코스의 단일 데이터 원본
- `src/game/scenes`: 부팅, 오프닝, 월드맵, 코스, 보스, 엔딩
- `src/game/systems`: 오디오, 저장, 입력, 코스 생성
- `src/ui`: Phaser 위에 올라가는 선명한 DOM HUD와 메뉴
- `public/assets`: 원본 라이선스를 유지한 픽셀아트·음악·효과음
- `docs`: 조사, 설계, 콘텐츠 및 검증 계약
